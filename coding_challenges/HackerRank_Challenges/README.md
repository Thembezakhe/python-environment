# HackerRank Challenges

This directory contains solutions to HackerRank challenges focused on SQL, Python, and data engineering concepts — used for interview preparation and skill development.

## Categories

* `python/` — Python problem-solving and scripting challenges
* `problem_solving/` — Algorithm and data structure challenges (Easy to Medium)
* `data_engineering/` — Python-based ETL, data manipulation, and pipeline-related challenges

> **Scope:** All challenges here are Python only. SQL challenges from HackerRank (and any other platform) are organised by SQL concept and maintained exclusively in the [sql-environment](https://github.com/Thembezakhe/sql-environment) repo under `InterviewPrep/`.

## Notes

* Solutions are written in Python 3 unless otherwise stated
* Each solution file includes the problem description as a comment at the top for context
